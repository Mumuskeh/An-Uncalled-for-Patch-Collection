-Module:
UI Inventory Mods Merged DLTXd

----------------------------------------------------------
-Compatibility:
(Some) original mods not required.

NOTE: You still need the original Knife and Pistol in Binoculars slot. Load it before the whole merge.

For compatibility with Outfit Attachments Overhaul, simply disable the file actor_status_thirst.script, or let OAO's have priority.

For compatibility with Banjaji's Pick up empty stash, disable its copies of item_backpak.script and ui_inventory.script.

----------------------------------------------------------
-Explanation:
A single user friendly, patch free solution for popular inventory mods, for those who play with the vanilla inventory with no overhauls.
Includes the functionality of:

- 1.5.3 additions to ui_inventory.script
- Bart's New Sorting Tabs [bartoche70]
	https://www.moddb.com/mods/stalker-anomaly/addons/barts-new-sorting-tabs-v14-for-rc18-only
- Patch Hunger, Thirst, Sleepiness Bars [legapon]
	https://www.moddb.com/mods/stalker-anomaly/addons/patch-hunger-thirst-sleepiness-bars
- Knife and Pistol in Binoculars slot [ravenascendant]
	https://www.moddb.com/mods/stalker-anomaly/addons/knife-and-pistol-in-binoculars-slot
- Faction & Rank Inventory [painecx]
	https://www.moddb.com/mods/stalker-anomaly/addons/faction-rank-inventory
- Modular Miscellaneous Tweaks - Shift module [Vintar0]
	https://www.moddb.com/mods/stalker-anomaly/addons/modular-miscellaneous-tweaks

New Sorting Tabs's extra icon filew was merged with everything else into the same 8mb texture file (seriously, it was a 32mb 4kx2k empty image with the icons in a corner).
