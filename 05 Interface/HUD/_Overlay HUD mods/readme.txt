-Module:
Various Overlay HUD Texturess Patches

----------------------------------------------------------
-Compatibility:
NOTE: You still need the original mods. Let these patches overwrite them.

----------------------------------------------------------
-Explanation:
I've noticed a bunch of HUD overlay mods to mipmap their textures. This struck me as strange. Aren't mipmaps supposed to be only for far away objects? And cause issues for interface textures? I've been told that, yes, that's correct, it's pointless and may cause interface issues.

NASA level computers may not care, but I resaved a bunch of these mods without mipmaps. In 1k, mind. To not bloat the downloads too much, but it should also load faster.

Not included in this package, but you can download them from the Github repo from the following links.
