-Module:
Various Overlay HUD Texturess Patches

----------------------------------------------------------
-Compatibility:
NOTE: You still need the original mods. Let these patches overwrite them.

----------------------------------------------------------
-Explanation:
I've noticed a bunch of HUD overlay mods to mipmap their textures. This struck me as strange. Aren't mipmaps supposed to be only for far away objects? And cause issues for interface textures? I've been told that, yes, that's correct, it's pointless and may cause interface issues.

NASA level computers may not care, but I resaved a bunch of these mods without mipmaps. In 1k, mind. To not bloat the download too much, but it should also load faster.

List of mods:
-Drunk's Miserable Masks [Drunk_Headcrab]
-Dynamic HUD Remade [DX8] [Mister_Scratch, Icarogib]
-Dynamic HUD Remade [DX8] Less Opacity [Mister_Scratch, Icarogib, ONICRAZYYY]
-Mask And Helmet Overlays Fixed [wmn955]
-Nav's Definitive Masks [navjotski]
