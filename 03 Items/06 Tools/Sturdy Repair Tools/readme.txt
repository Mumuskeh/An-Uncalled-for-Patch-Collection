-Module:
Sturdy Repair Tools

----------------------------------------------------------
-Compatibility:

Other similar modules in this pack are compatible.

Filled Box of Matches and OctaviaMG's Knife and tool sharpening rework have higher priority and will apply their changes on top.

----------------------------------------------------------
-Explanation:

Increases the maximum uses for tools and repair kits, multiplied by five. Shrimple as that.
Tools with 2 use will have 19, 21 if 4, 25 if 5, 30 if 6.

Some exceptions are:
File and Ramrod:		100
Basic sewing thread:	30
Field armour toolkit:	20
Grooming set:			Lasts longer than before, but not much.
Swiss knife.			Should last twice than vanilla.
Multitool:				Takes about disassembling 5~ guns to drop 1%.

No particular balance was intended, this is strictly a QoL convenience for those who think a goddamn file being used up with two applications is bonkers, or your nice cleaning kit being useless after 3 cleans is lame, bogus and wack.
