Changes in original version: The Three-piece sharpening stone set now has 204 uses instead of 4.

changes in balanced version: The Three-piece sharpening stone set now has 204 uses instead of 4.
                             Price of the Three-piece shapening stone set was adjusted to 9495 Rubles.
                             Weight of the Three-piece sharpening stone set was changed to 0.56kg.
                             Effectiveness of the Three-piece sharpenign stone set was lowered to 3%

Where i got the numbers from.
The max uses comes from a forum post where a person says his grindstone set lasts him two
 years, and he uses it 6 times a year to sharpen 17 blades, this means he can sharpen 17 tools 12 times 
before needing to replace his set, this totals to 204 sharpens before need for replacement. The price 
was achieved by me finding the price of a simple three-piece grindstone set where i live, increasing 
the price slightly, converting that number to hryvnias by 2018 prices, and than to rubles. Effectiveness
on the optional balance version was given to me by Theisgood on the comment section of the addon, should
allow you to repair 2-4 knives to make things more balanced.
