-Explanation:

It will be treated as a medkit. While it uses a bandaging animation and works as such, that seems odd, as AFAKs are more akin to first aid kits to be attached to your chest plate. So instead it will act as a quicker acting Army Medkit with more uses. Crafting and new game costs will reflect this.
If using the Simple Bandage Overhaul in this package, make sure it's overwriten by this module.
Not intended/prepared for BHS or the patch for it.

New game costs are now increased to at least match equivalent vanilla medkits.

Removed from most suppliers, and standardized distribution to medics, Sakharov, Hermann and Sid. Support for Basic Trader Profiles Expansion.
