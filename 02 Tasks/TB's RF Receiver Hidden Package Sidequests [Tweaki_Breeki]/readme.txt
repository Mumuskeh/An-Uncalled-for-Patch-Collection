-Module:
TB's RF Receiver Hidden Package Sidequests [Tweaki_Breeki] + CookBook's QOL patch [Aeonera]

----------------------------------------------------------
-Compatibility:
NOTE: You still need the original mods. Let this overwrite them both.

----------------------------------------------------------
-Explanation:

The new tasks in TB's mod rewards you with a particular package of goodies (the content determined by that of the packages in vanilla courier tasks), and a random selection of extra loot, drawn from some tables. The original tables are three: loot (some food, meds, and IEDs), upgrades (weapon and armor upgrade kits), and junk (actually artefacts).
Aeonera's patch also adds an option to change the upgrades table for another filled only with the universal kits from Streamlined Upgrades.

This module works upon Aeonera's changes, so both mods are required.

To begin with, I remove the MREs and IEDs from the loot table.

1) new "Utilities" table, for things that are useful but finite. Ie: aluminium frames, kevlar plates, camelbak, cleaning and sewing kits. The IEDs are moved here from the loot table.

2) factional tables. Currently they only have army and scientist medkits, stimpacks, and MREs, each type depending on faction (ie: Army players get army medkit and stimpack, and the UKR MRE).

3) improved tables for utilities, upgrades, and Streamlined Upgrades, used when you've reached veteran rank (assuming vanilla behavior for items of higher value (ie: titanium grid).
Currently, the upgrades and Streamlined Upgrades tables have the same contents as teh normal tables. But they can still be patched to add items from other mods.

The junk table will now only include junk artefacts; this way at lower ranks you only get some cash trash, but nothing that starts making you superhuman.
Once you're ranked up a bit, you then will be able to receive useful artefacts, and no more junk ones.
Once you've ranked up to master, you'll ALSO be able to find Heart of the Oasis, Death Lamp, and Compass. Why? Because people love you or sumthin iunno. (ok fine it's because Artefact Varionatizer fucks the quest artefacts and I wanted more ways to source them up, so I said might as well).

Other modules in this package and Uncle Yar's Workshop may use the new table. If they include this mod as an integration, they'll need this module.


The list of potential hostiles that spawn at the package is also tweaked to observe your rank; the higher you are, the stronger the NPCs you'll find.
