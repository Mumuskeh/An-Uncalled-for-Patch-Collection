-Compatibility:
NOTE: You still need the original mod, or Drunk's Overhaul. Disable the configs/creatures folder.

Drunk's overhaul raises the eye_rance value for the [stalker] section from 160 to 220. If you want that increase, open mod_system_steath.ltx and do the appropiate change.

Don't use Stealth's patch for Death Animations. Use DLTX Minimod's instead.

----------------------------------------------------------
-Explanation:

Minor DLTX conversion.
HUD icons compressed.

Mind, neither change solves anything serious. The icon files were already pretty small, and I'm not aware of many mods that conflicted with the same config files. But if you find a conflicting mod or want the icons to be speedier, well, you can use this.
