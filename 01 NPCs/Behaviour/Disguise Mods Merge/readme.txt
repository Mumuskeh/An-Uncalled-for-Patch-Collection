Disguise Mods Merge

----------------------------------------------------------
-Compatibility:
You don't need the original mods:

	-Vintar0's Companions don't blow Disguises - Enhanced (Tosox Mini Mods)
	-Improved Disguise System [bartmech]
	-Banjaji's Undercover communications

----------------------------------------------------------
-Explanation:

There was a mod merge, "Disguise addons merge - bartmech's IDG, Banjaji's UCC, Catspaw's CDPF v1.0.1". I t merged Bartmech's and Banjaji's mods above with Catspaw's Companion Disguise Patch Fix.
Both Banjaji's and Catspaw's included Vintar0's original Companions don't blow Disguises, and Catpsaw's expanded it a bit.
However, Tosox updated it to do the same as Catspaw's, and from what I see, a bit more elegantly (no extra function, everything done in existing lines of code).

This is a recreation of that merge, which you can still use it, it should still be fine! But swapping Catspaw's code for Tosox's. Unfortunately I'm not good enough with monkey patching, but it should be good.
