-Module:
Skin boars with any knife

Thanks to Igigog for the help.

----------------------------------------------------------
-Compatibility:

It won't work if some other mod modifies the "strong_monster" table in item_knife.script, in a way that 'boar' is not its first entry.

If you find such a case, some other mutant will be removed from the table instead. You may edit item_knife_skinboarspatch.script and change the "1" for whatever place 'boar' is found in the table.

----------------------------------------------------------
-Explanation:

Monkey patch that allows skinning boars with weak knifes. Merely a test for removing data through monkey patching, instead of adding.

There's a mod in Moddb with the same intent. It's unnecesary with this much more compatible option.
