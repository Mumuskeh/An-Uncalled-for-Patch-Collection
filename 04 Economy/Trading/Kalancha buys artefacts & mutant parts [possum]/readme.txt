-Module:
Kalancha buys artefacts & mutant parts [possum]

----------------------------------------------------------
-Compatibility:
Original mod not required.

NOTE: This feature is already included in Basic Trader Profiles Expansion. Avoid using this module with that mod.

----------------------------------------------------------
-Explanation:
DLTX conversion.

Trader file renamed to conform to the naming in vanilla files. trade_factionname_NPCname.ltx, that is, trade_csky_kalancha.ltx, instead of the original trade_Kalancha.ltx.
This in itself is no great change in respect to the previous changes or the original mod, you still get the same functionality.
It however makes slightly easier to work with trade files for adding items to Kalancha this way, and some of the modules in this package for mods adding new medical items (ie: No_data's, Drugs That Make Sense) now include support for this new trade file.
