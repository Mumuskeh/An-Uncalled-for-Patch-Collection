-Module:
Beard - Artifact Hunter [agoodsetofpistol]

----------------------------------------------------------
-Compatibility:
Original mod not required.

NOTE: This feature is already included in:
- Trader Overhaul
- Basic Trader Profiles Expansion
Avoid using this module with either mod.

----------------------------------------------------------
-Explanation:
DLTX conversion.

Trader file renamed to conform to the naming in vanilla files. trade_factionname_NPCname.ltx, that is, trade_stalker_beard.ltx, instead of the original trade_beard.ltx.
This in itself is no great change in respect to the previous changes or the original mod, you still get the same functionality.
It however makes slightly easier to work with trade files for adding items to Kalancha this way, and some of the modules in this package for mods adding new medical items (ie: Eurodrinks, DLTX Minimod's New Food) now include support for this new trade file.
