NOTE: This feature is already included in Basic Trader Profiles Expansion.
Avoid using this module with that mod.

----------------------------------------------------------
-Explanation:
Not wide enough to be considered a trade overhaul, this merges a few mods affecting what and how traders sell and buy. It includes:

- More Price For Animal Parts (DLTX MiniMod)
- Mechanics Sell More Junk (DLTX MiniMod).
	(With a tweak: the higher goodwill, they sell you more parts and cheaper.)
- Traders Sell All Tools Based On Rep (DLTX MiniMod)
- Traders Sell Recipes [megamurmulis]
	(The option for higher price, reputation depending.)
